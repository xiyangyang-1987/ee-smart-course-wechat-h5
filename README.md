# 电工电子课程设计（二）智慧课堂 H5

本目录是可挂到认证微信公众号自定义菜单的 HTTPS H5 课堂应用。公众号提供入口，H5 提供数字电子时钟工程诊断、基于检查结果的补偿/标准/拓展学习路径、匿名提交码和教师端班级汇总，覆盖 555 时基、74LS90 / 74LS160 计数器及 DCD_HEX / 74LS48 显示方案。

这是一套纯静态应用：不调用外部 AI、不接入数据库，全部记录保存在学生自己的浏览器里，通过“导出档案 / 反馈包”在师生之间传递。

## 学生端：四个模块顺序解锁，过程不能跳过

| 模块 | 内容 | 解锁条件 |
| --- | --- | --- |
| 一 · 课前预习 | 3 张知识卡（原理图、速查表、自检清单）+ 课前自测 | 3 张卡标记掌握 且 自测答对 ≥ 2/3 |
| 二 · 课中知识卡 | 可交互课程知识图谱 + 6 张诊断知识卡 | 至少 4 张通过判据校验 |
| 三 · 故障排除 | 6 类典型故障 → 下一测点 / 判据 / 建议动作 | 完成一次真实“运行检查并保存” |
| 四 · 工程档案 | 六阶段工程证据 + 教师反馈导入 | — |

未达标时后一模块只显示“还差什么”，即使直接改地址也无法跳步。

## 课程知识图谱

6 个功能模块（时基 §1、计数 §2、译码显示 §3、进位与回零 §2.2—2.4、调时与去抖 §8、拓展与稳定 §4.3·附录7.3）、21 个知识点、13 条先修与信号依赖。实线表示模块归属，虚线表示先修关系；点击任意节点可查看原理、公式、常见错误、测点与关联知识卡。另提供“能力与评价”“故障诊断链”两个视图。

## 教师端：十维结构评分

教师在“课后教师评阅”中选择单个 `.ms14` 或整个“课程文件”文件夹，系统按十个维度给出结构分与 A–E 等级：

时基器件与时钟源、555 引脚规范性、计数链完整度、计数器引脚规范性、显示与译码链、数码管输入规范性、关键引脚治理、进位与回零逻辑、调时与去抖、网络与端口连接质量。

同时标出**致命连接缺陷**（计数器时钟输入悬空、555 输出端悬空、555 复位端未接 VCC、数码管 BCD 输入悬空）与**时钟源规范性问题**（使用 CLOCK_VOLTAGE 理想方波源）。

> 结构分只用于定位证据缺口、安排课堂追问，**不是课程成绩**。正式成绩仍以 Multisim 源文件、实测波形、实验报告与答辩为准。

## 课堂数据边界

- 学生只使用小组代号，不输入真实姓名、学号或手机号。
- 预习进度、诊断记录与阶段证据保存在当前设备；学生导出匿名档案 JSON 或提交码发送给教师。
- 教师在教师工作台导入后本地汇总，可导出分析。
- 本版本不调用外部 AI、不接入实时数据库；规则知识库由教师审核，是后续接入学校生成式 AI 的可控底座。
- 学生端的 `.ms14` 文件只在浏览器内解码，不上传原始电路文件。

## 公众号配置

将部署后的 `index.html` HTTPS 地址配置为认证公众号自定义菜单链接，并完成微信网页授权域名白名单配置（如后续接入身份认证）。

## 本地部署

本目录为纯静态资源，可直接由任意 HTTPS 静态托管承载（GitHub Pages、学校智慧教学平台等）。

- 功能需要 `localStorage`，因此建议通过 HTTPS 或 `http://localhost` 访问。
- PWA 离线缓存在 HTTPS 下自动启用（`sw.js`），HTTP 环境下会自动跳过，不影响功能。
- 页面内所有教学示意图均为内联 SVG，断网也能正常显示。
