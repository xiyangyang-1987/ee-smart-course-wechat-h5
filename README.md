# 电工电子课程设计（二）智慧课堂 H5

本目录是可挂到认证微信公众号自定义菜单的 HTTPS H5 课堂应用。公众号提供入口，H5 提供数字电子时钟工程诊断、基于检查结果的补偿/标准/拓展学习路径、匿名提交码和教师端班级汇总，覆盖555时基、74LS90/74LS160计数器及DCD_HEX/74LS48显示方案。

## 课堂数据边界

- 学生只使用小组代号，不输入真实姓名、学号或手机号。
- 诊断记录保存在当前设备；学生复制匿名提交码发送给教师。
- 教师在“学习分析”粘贴提交码后本地汇总，可导出班级分析。
- 本版本不调用外部 AI、不接入实时数据库；规则知识库由教师审核，是后续接入学校生成式 AI 的可控底座。

## 公众号配置

将部署后的 `index.html` HTTPS 地址配置为认证公众号自定义菜单链接，并完成微信网页授权域名白名单配置（如后续接入身份认证）。
